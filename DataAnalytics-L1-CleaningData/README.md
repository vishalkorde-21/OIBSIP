# Titanic Data Cleaning and EDA Project

## Project Overview
This project focuses on cleaning and performing Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## Tasks Performed
- Loaded and inspected the dataset.
- Checked and handled missing values.
- Removed duplicate records.
- Analyzed passenger survival by gender and passenger class.
- Created visualizations to understand survival patterns.
- Summarized key findings.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files Included
- `cleaning_data_analysis.ipynb` — Data cleaning and EDA notebook.
- `Titanic_messy.csv` — Original dataset.

## Conclusion
The analysis helped identify missing data, prepare the dataset for analysis, and explore passenger survival patterns across gender and passenger class.
